# 快速抓取前加入 SONIC 行走

目标：机器人从成功快速版操作位向后平移约 0.81 m（首次试验为 0.90 m；依据干净停步的实测双脚落点校准），场景与瓶子不变；使用 SONIC planner 走回操作位，经过实际稳定性检查后接入原来的 586 帧快速抓取 token。首次控制前恢复一次平移后的初始状态，执行期间不重置机器人位置。

控制：SONIC V2 target_vel planner → 未来关节位置/速度和相对根朝向 → release encoder → release decoder → 29 个身体关节 PD target。Revo2 手指目标单独控制。行走、站稳和抓取使用同一个 release decoder，保留其实时状态历史；没有在线 IK 覆盖。抓取阶段原始 fast token 和手指目标不变。

本次不只是放大步幅，还改用在线参考编码及实时根朝向锚点，因此成功或失败不能单独归因于步幅。在线闭环生成的 token 也不等同于事后将测得轨迹离线编码。

离线筛选：巡航速度从 0.25 增至 0.55 m/s，planner 预测的左右脚相对身体前后运动范围由约 14–15 cm 增至 25–31 cm。这是参考运动范围，不是已经测得的物理步长。实际效果见各运行的 audit.json。

验收：前进至少 0.80 m；抓取开始时根部平面误差不超过 5 cm，双脚及身体稳定；完整执行快速抓取；最终连续严格悬空至少 3 s、有对向手指接触；监测到的手/前臂桌面接触力不超过 0.05 N；最终 3 s 瓶子相对手腕位移不超过 15 mm、旋转不超过 10°。

视频为 Isaac Sim 原生预览，非 RT2 管线。物理成功、视频检查、训练数据可用性分别记录；默认 training_ready=false。

运行：`run.py --name NAME`，同时运行 `supervise.py runs/NAME`。阶段检查需要当前会话检查图像后写入 reviewed_NNN.json；不能跳过实际状态门槛。审计：`audit.py runs/NAME`。

站位校准：从 walk_fast_004 的实测脚中心与快速版初始脚中心相对根部偏移，计算初始机器人和 planner 导航目标共同平移 [0.0117483, 0.0890828, 0] m。导航目标与最终操作目标分开记录；前者补偿停止与姿态切换的落点偏差，后者保持原快速版操作位。此几何估计必须经过实际 rollout，不能视为到位成功。停止后禁止近桌反复导航。
