# 已保存 SONIC token 的本地执行性能与位姿复测

实验日期：2026-10-07。所有运行均为真实物理执行。原实验、资产、token、控制增益和接触门槛未修改。
无相机执行区间：146.826 ± 2.262秒；有相机：173.080 ± 1.555秒（均值±样本标准差）。两组均值差26.254秒。

关闭细粒度计时但保留相同状态记录的对照为145.100秒；与三次细计时无相机均值相差1.726秒。这是一轮对照，差异混有运行噪声，不能全部认作计时器开销。

在这套配置下，物理步进、接触传感器、场景更新和观测计算合计占无相机执行区间约87.2%；decoder约0.83%（每次约1.139毫秒）。本地主要开销集中于仿真及其传感器/框架更新。


## 条件与计时边界

- 固定 `20261001_lean_capture/candidates/generated_replay_001` 的1071帧实际token（21.42秒仿真），相同初态、seed17；每轮新进程。
- SONIC release decoder在CPU上运行，ORT intra/inter线程2/1；全部29身体关节由decoder驱动，双手各6维目标单独执行。无在线encoder、planner、IK或GPT请求。
- 以仿真时间计物理200Hz、控制50Hz，保留双手/前臂/房间接触监测与稳定持瓶验收。
- 三次无相机与三次第一视角相机交替执行；相机使用原lean相机640×480、原生25Hz、存储50Hz、DLAA。另做一次关闭细粒度计时但保留状态记录的对照。
- rollout从首次控制入口到最后控制返回；包含阶段监督、推理、物理、接触、采集、控制间隙。进程总时长还包含加载和退出。
- 使用嵌套exclusive墙钟时间，子调用不重复累加。没有额外CUDA synchronize；异步GPU等待可能归入后续读取，不能将这些数字当成纯GPU核函数时间。
- 当前驱动580.178.04；历史存在580.173.02临时库。此次使用当前已匹配驱动，不加载旧兼容库。因此跨日期比较不作为严格速度收益。

## 验证与限制

- 数值审计全部通过：True。每轮1071次decoder、4284个物理步与接触样本（细计时对照除外：无调用计数器，但接触样本数仍核对）。实际decoder输入前64维逐值匹配冻结token。
- 位姿记录和计时有测量开销；`control_no_detail`仅控制细粒度计时开销，仍记录同样状态，不是完全无探针基线。
- 固定初态重复验证不代表位置/摩擦扰动泛化或真机可靠性。
- 相机视频为性能对照与视觉诊断素材，不是已验收训练数据；完整视觉结论见各轮 `visual_realism_review.json`。
- 单次冻结token回放不测encoder/planner耗时，也不包含GPT策略探索、失败重试或最终数据集导出。
